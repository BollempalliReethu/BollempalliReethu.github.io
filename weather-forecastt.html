Weather Forecasting Web Application

Built a responsive weather application that provides real-time weather information for any city using a weather API, with an intuitive, dynamic user interface.

Live & Working

Overview

  • Designed and developed a fully responsive weather forecasting website that works across desktop and mobile screens.
  • Connected to the OpenWeather API to fetch real-time weather data for any city entered by the user.
  • Implemented dynamic display logic in vanilla JavaScript to update temperature, conditions, and forecast details without a page reload.

What it solves

  • Gives users quick, accurate weather information for any location in a clean interface, without needing a dedicated app.
